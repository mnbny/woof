# Woof project brief

## Purpose

Woof will be a command-line application. Its product behavior, users, and integrations have not been specified.

## Current scope

The repository provides development scaffolding based on `~/Dev/maacs`: pinned dependencies, strict TypeScript, formatting and linting, sequential validation, bundled distribution, source execution, shell completion, test infrastructure, editor settings, Paseo setup, and agent documentation.

The CLI exposes help, version information, and shell completion. There are no product commands.

MAACS commands, application utilities, prompt and skill catalogs, resource validators, and product tests are not part of Woof. Project-local skills are intentionally absent; the developer uses globally installed skills.
